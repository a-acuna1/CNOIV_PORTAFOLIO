1. PERFILADO DE IMAGEN Y EXTRACCIÓN DE CREDENCIALES

Se inició el análisis determinando el perfil del sistema operativo a partir de la estructura KDBG de la imagen. La marca de tiempo local de la memoria capturada fue identificada como 2018-08-04 22:34:22 +0300, bajo una arquitectura Win7SP1x64[cite: 202].

>_ PERFILADO DEL VOLCADO
.\volatility_2.6_win64_standalone.exe -f OtterCTF.vmem imageinfo

Posteriormente, se procedió a extraer la contraseña de texto plano almacenada en memoria para el usuario Rick (el perfil activo del cibercriminal "Morty"). Esto se logró combinando los módulos hashdump y lsadump[cite: 203].

>_ EXTRACCIÓN DE CONTRASEÑA LSA
.\volatility_2.6_win64_standalone.exe -f OtterCTF.vmem --profile=Win7SP1x64 lsadump

> Contraseña recuperada: M.o.r.t.y.I.S.R.e.a.l.l.y.A.n.O.t.t.e.r[cite: 203]

2. INVESTIGACIÓN DE RED Y PROCESOS MALICIOSOS

Se analizó la tabla de conexiones de red activas durante el volcado de memoria. Se identificó la IP Local (192.168.202.131)[cite: 203, 204] y la conexión hacia un servidor malicioso (C2)[cite: 206] externo:

>_ CONEXIONES DE RED ACTIVAS
.\volatility_2.6_win64_standalone.exe -f OtterCTF.vmem --profile=Win7SP1x64 netscan
  • Proceso: LunarMS.exe (PID 708)[cite: 206]
  • IP Destino (C2): 77.102.199.102 : 7575[cite: 206, 207]
  • Geolocalización del Atacante: Londres, Inglaterra[cite: 207].

Asimismo, se extrajo el nombre de la computadora interrogando directamente la clave del Registro del Sistema (WIN-LO6FAF3DTFE), lo cual permite vincular el equipo a otras evidencias recolectadas por inteligencia[cite: 205].

>_ NOMBRE DEL ORDENADOR (REGISTRY)
.\volatility_2.6_win64_standalone.exe -f OtterCTF.vmem --profile=Win7SP1x64 printkey -K "ControlSet001\Control\ComputerName\ComputerName"
3. EXTRACCIÓN DE ARTEFACTOS: CORREOS Y BILLETERA BTC

Se realizó un volcado completo de la memoria del proceso del navegador (chrome.exe - PID 4076) para buscar direcciones de correo electrónico utilizadas para ingeniería social[cite: 206, 208].

>_ VOLCADO DE PROCESO (CHROME)
.\volatility_2.6_win64_standalone.exe -f OtterCTF.vmem --profile=Win7SP1x64 memdump -p 4076 -D .

> Correos identificados: rickypinky@mail.com, rickopicko@mail.com[cite: 208].

Finalmente, se investigó el proceso PID 3720 (vmware-tray.exe), el cual ocultaba el malware real. Se volcó la memoria de este proceso y se filtró usando una expresión regular para detectar la billetera de criptomonedas vinculada a las extorsiones de la botnet[cite: 208].

>_ EXTRACCIÓN DE BILLETERA BITCOIN
Select-String -Path .\3720.dmp -Pattern "[13][a-km-zA-HJ-NP-Z1-9]{25,34}"

> Billetera BTC: 1MmpEmebJkqXG8nQv4cjJSmxZQFVmFo63M[cite: 208]

Nota: Al consultar bases de datos de inteligencia sobre amenazas, esta dirección aún no figuraba en las listas negras de "BTC Black It"[cite: 209].
