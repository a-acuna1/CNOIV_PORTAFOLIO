1. RESUMEN EJECUTIVO Y METODOLOGÍA

Se realizó una evaluación de seguridad ofensiva sobre el servidor corporativo "My File Server 1", simulando un atacante externo sin credenciales ni conocimiento previo del sistema. Se adoptó el estándar PTES por su cobertura completa del ciclo ofensivo a nivel de sistema y red, abarcando desde el descubrimiento del objetivo hasta la escalada de privilegios.

El sistema fue comprometido en su totalidad, identificando 5 vulnerabilidades (2 de ellas críticas) que permitieron obtener control absoluto sin necesidad de credenciales previas.

2. HALLAZGOS IDENTIFICADOS Y ESCALADA
Hallazgo Impacto / Vector Severidad

4. EVIDENCIAS TÉCNICAS (OPERACIONES EN TERMINAL)

>_ FASE 1: RECONOCIMIENTO

Validación de la interfaz de red local en la máquina atacante (Parrot OS).

Descubrimiento de hosts mediante netdiscover e intercepción de tráfico ARP, confirmando la IP del objetivo (192.168.56.104).

>_ FASE 2: ENUMERACIÓN

Escaneo exhaustivo de puertos con nmap, revelando servicios críticos como FTP (21, 2121), SSH (22), HTTP (80) y SMB (445).

Enumeración de recursos compartidos en SMB utilizando smbmap, detectando el recurso 'smbdata' con permisos de lectura/escritura y el usuario 'smbuser'.

>_ FASE 3: EXPLOTACIÓN INICIAL

Análisis de vulnerabilidades web con nikto, identificando el archivo expuesto /readme.txt.

Lectura del archivo readme.txt desde el navegador, revelando la contraseña en texto plano.

Verificación de acceso anónimo en el servicio FTP del puerto 21.

Generación de un par de llaves criptográficas con ssh-keygen en la máquina atacante para inyectarlas posteriormente en el servidor.

Acceso exitoso al segundo servicio FTP (puerto 2121) utilizando las credenciales obtenidas (smbuser / rootroot1).

>_ FASE 4: ESCALADA DE PRIVILEGIOS

Compilación y ejecución del exploit de DirtyCOW (40616.c). Se sobrescribe /usr/bin/passwd, se obtiene una shell de root y se captura la bandera proof.txt.
